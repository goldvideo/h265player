🎬 GoldPlay H265 播放器 - MP4 支持测试

新功能：本版本除支持 HLS 流外，现已支持 MP4 格式！
播放器会自动检测媒体类型并使用相应的协议处理器。

📂 加载媒体

📖 使用指南

初始化

初始化支持 MP4 的播放器：

let player = new GoldPlay(document.getElementById('goldplay-container'), { sourceURL: 'http://127.0.0.1:8000/h265player/data/mp4/song_h265.mp4', // MP4 文件 URL type: 'MP4', // 指定 MP4 类型 autoPlay: true, libPath: './dist/lib/', // WASM 库路径 poster: 'http://127.0.0.1:8000/h265player/data/mp4/poster.jpg' // 可选的封面图 });

支持的媒体类型

  • HLS (.m3u8) - 原始格式
  • MP4 (.mp4) - 新增支持
  • H.265/HEVC 视频编解码器
  • AAC 音频编解码器

主要特性

  • 根据文件扩展名自动检测类型
  • 为 HLS 和 MP4 格式提供无缝播放
  • 现有 HLS 接口无需任何改变
  • 与所有现有控件和功能兼容
  • 使用 HTTP Range 请求高效流媒体传输

⚙️ MP4 配置选项

使用 MP4 文件时，可以配置以下选项：

const mp4Options = { sourceURL: 'path/to/video.mp4', // 必需：MP4 文件 URL type: 'MP4', // 必需：设置为 'MP4' autoPlay: true, // 自动开始播放 preload: true, // 预加载元数据 startTime: 0, // 开始位置（秒） poster: 'path/to/poster.jpg', // 封面图 libPath: './dist/lib/', // 解码器库路径 maxBufferLength: 5000, // 最大缓冲时长（毫秒） controlBarAutoHide: true, // 自动隐藏控制栏 controlBarAutoHideTime: 3, // 自动隐藏时间（秒） processURL: (url, segment) => url // 可选：请求前处理 URL }; let player = new GoldPlay(container, mp4Options);

🔧 实现细节

架构

MP4 支持通过以下组件实现：

src/ ├── toolkit/ │ └── MP4Parser.js // MP4 元数据提取 ├── loader/ │ └── MP4Loader.js // MP4 文件加载 ├── demux/ │ └── MP4Demux.js // MP4 解封装 └── data-processor/ └── dataProcessor.js // 更新以支持 MP4

工作原理

  1. 类型检测：播放器从 URL 或选项中检测媒体类型
  2. 元数据加载：MP4Parser 读取文件头（moov 原子）以提取时长、分辨率和轨道信息
  3. 分段处理：文件被逻辑分为 2 秒的段进行流传输
  4. 解封装：MP4Demux 分离视频和音频流
  5. 解码：使用现有解码器对 H.265 视频和 AAC 音频进行解码
  6. 播放：视频渲染到 Canvas，音频通过 Web Audio API 播放

🧪 使用示例文件测试

注意：请将以下示例 URL 替换为服务器上实际的 MP4 文件。

// 使用本地 MP4 文件测试 const testURL = 'http://localhost:8000/sample.mp4'; // 或使用公开测试文件（如果可用） // 确保正确配置 CORS 头： // Access-Control-Allow-Origin: * // Accept-Ranges: bytes

服务器要求

  • 启用 CORS 头（Access-Control-Allow-Origin）
  • 支持 HTTP Range 请求（Accept-Ranges 头）
  • 返回正确的 Content-Length 头
  • 支持 moov 原子在 MP4 文件的开头（推荐）

🌐 浏览器兼容性

MP4 支持需要：

  • WebAssembly 支持（H.265 解码器）
  • Web Audio API（用于音频播放）
  • Canvas API（用于视频渲染）
  • ArrayBuffer 和类型化数组
  • 现代浏览器（Chrome、Firefox、Safari、Edge）

⚠️ 故障排除

常见问题

问题：播放器无法加载 MP4
✓ 验证 URL 正确且启用了 CORS
✓ 检查浏览器控制台的错误信息
✓ 确保 MP4 文件有正确的结构，包含 moov 原子
✓ 验证 libPath 指向正确的解码器库
问题：音视频不同步
✓ 确保 MP4 文件有有效的 PTS 时间戳
✓ 检查网络稳定性
✓ 验证音频编解码器是 AAC（其他格式可能不受支持）
问题：快进不工作
✓ 验证服务器支持 HTTP Range 请求
✓ 检查 MP4 文件元数据是否正确解析
✓ 确保 MP4 文件包含快进目标的关键帧
